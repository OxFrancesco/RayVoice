# RayVoice setup

This extension needs an **ElevenLabs API key**.

1. Sign up at https://elevenlabs.io (free tier works).
2. Go to **Settings → API keys** (https://elevenlabs.io/app/settings/api-keys) and create a key.
3. Paste it into the **ElevenLabs API Key** preference field.

Optional: pick Voice IDs from https://elevenlabs.io/app/voice-library (click a voice → copy its ID). Defaults (Rachel + George) work fine.
